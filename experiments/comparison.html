方案清单

  1. YouMi Agent — 本框架 2026 · 本项目：多 Agent DAG 骨架复用 + 工具经验沉淀，双闭环自进化
  2. APC — NeurIPS 2025 · Stanford：test-time memory：提取计划模板，关键词匹配 + 小模型适配
  3. AgentReuse — 计算机研究与发展 2024 · 中国科学技术大学：意图分类 + 关键参数识别的计划复用
  4. LEGOMem — AAMAS 2026 · Microsoft：模块化 procedural memory：任务轨迹拆成可复用 memory units
  5. ExpeL — AAAI 2024 · UCLA / UIUC：从成功/失败经验提取规则，Agent 自进化
  6. Reflexion — NeurIPS 2023 · Northeastern / MIT：语言化自我反思（verbal RL），从反馈改进
  7. Voyager — (arXiv) 2023 · NVIDIA / Caltech：技能库（code-as-skills）+ 自动课程，开放世界持续学习
